B+ 木オンディスク KVS — インタラクティブ解説

このサイトは bptree/ の Go 実装と同じアルゴリズムで動く 縮小シミュレータ (shared/bptree-sim.js) を駆動し、 木構造・ノード内要素・ノード間接続・要素移動・ラッチ状態を アニメーションで可視化する。 描画はすべてシミュレータの発行するイベント列から生成されるため、 図は常にアルゴリズムの実動作と一致する。

縮小定数: 画面上は MAX=4 / MIN=2 (実装の 510/255 に対応) で動作させ、 少数キーで分裂・併合が起きるようにしている。

1. 要素探索 Get: R ラッチのクラビング下降、葉での二分探索、ヒット/ミス 2. 要素挿入 Put: W クラビング、安全な子での祖先解放、upsert 3. 挿入にともなうノード挿入 allocPage、nextLeafPID 配線、親への (sep,child) 挿入 4. 挿入にともなうスプリット 葉のコピーアップ vs 内部の昇格、分裂の上向き伝播 5. 要素削除 Delete: leafRemoveAt、安全判定、不在キー 6. 削除時のマージとノード削除 借用/マージ、TryLock+リスタート、freePage→フリーリスト 7–9. 木構造の変化 ルート成長 (高さ+1)、分岐追加、ルート縮小 (高さ−1) 全体概観 (v1) 従来の単一ページ解説: ページ/バッファプール/レイアウトの図版
