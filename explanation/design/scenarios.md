# デモの初期状態と操作

各HTMLの `prep` が初期状態を作り、`ops` が可視化する操作です。準備時の操作は再生しません。

共通の基準木は `[10,20,30,40,50,60,70]` を順番に挿入して作ります。値はキー×100。最大4件、最小2件です。

| ページ | 操作 | 見るポイント |
|---|---|---|
| get | Get(40), Get(35) | 発見／不在、子のR取得後に親のR解放 |
| insert | Put(35,3500), Put(40,9999) | 右シフト／上書き、安全な子で祖先解放 |
| node-insert | 80まで準備してPut(90) | 分割、next配線、親への分岐追加 |
| node-insert | Delete(20), Put(80)を準備してPut(90) | freelist再利用 |
| split | 80まで準備してPut(90) | 葉の分離キーはコピー |
| split | 10から120まで10刻みで準備してPut(130) | 内部の中央キーは昇格、新ルート |
| delete | Delete(70), Delete(999) | 下限を維持する削除／不在 |
| merge | Put(45)を準備してDelete(20) | 右借用 |
| merge | Put(45), Delete(70)を準備してDelete(60) | 左借用、TryLock失敗注入の場合は原状回復 |
| merge | Delete(20) | 右マージ |
| merge | Delete(70)を準備してDelete(60) | 左マージ |
| merge | 基準木に75,80,85,90,95,100を追加してDelete(20) | 内部マージとルート縮小 |
| structure | 40まで準備してPut(50) | 高さ1→2 |
| structure | 80まで準備してPut(90) | 高さ2のまま分岐追加 |
| structure | 50まで挿入し40を削除した状態からDelete(50) | 高さ2→1 |

コード対応は `shared/lesson.js`、原文は `shared/go-source.js`。実行していないGoコードを手書きで似せた抜粋や固定行番号表は使いません。
