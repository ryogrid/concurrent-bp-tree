6. 要素削除時のノードのマージとノードの削除

削除で count < Min になったノードはアンダーフロー (赤枠)。 修復は2段構え:

  1. 借用 (redistribution) — 兄弟が Min より多く持っていれば 1 エントリ分けてもらう。親の分離キーも更新される。
  2. マージ — 兄弟も Min しか持たなければ合体し、 余ったノードは freePage でフリーリストへ (meta 行の freelist に注目)。

右兄弟への処理は通常の左→右ラッチ順で安全に取れるが、 左兄弟は順序違反になるため TryLock を使う。 失敗したら全ラッチを解放して操作を最初からやり直す (デモ B)。

デモ A: 右借用 — 準備 put(45) → del(20)

L1 [10] がアンダーフロー。右兄弟 L2 [30,40,45] は Min 超過なので 先頭の 30 を借り、親の分離キーを 40 に更新。

デモ B: 左借用 + TryLock — 準備 put(45),del(70) → del(60)

L3 [50] がアンダーフローで右端 (左兄弟しかいない)。 L2 への TryLock が成功すれば末尾の 45 を借りる。 2本目のデモは TryLock を意図的に失敗させた演出: 全ラッチ解放 → 最初からやり直し (再降下ではキー60は既に消え found=false だが、削除成功は前回の結果で維持される — Go の ok = ok || removed と同じ)。

デモ C: 右マージ — del(20) (基準木)

L1 [10] がアンダーフロー、右兄弟 L2 [30,40] は Min なので借用不可 → L2 を L1 に吸収し L2 を解放。親から分離キー 30 と子ポインタが消える。

デモ D: 左マージ — 準備 del(70) → del(60)

L3 [50] がアンダーフロー、左兄弟 L2 は Min → L3 を L2 に吸収。

デモ E: 内部ノードのマージ + ルート縮小 — 高さ3の木で del(20)

葉マージが親をアンダーフローさせると内部ノードのマージが起きる。 内部マージでは親の分離キーが子に引き下ろされる (分裂の昇格の逆操作)。 ルートが子 1 つになれば高さが 1 減る (root shrink)。
